# TNTCargo

**TNTCargo** est une page vitrine développée entièrement en HTML avec du CSS intégré. Ce projet a été codé dans SPCK Editor.

## Présentation

TNTCargo est un site statique conçu pour présenter une entreprise ou un service de manière professionnelle et simple. Le design et la mise en page ont été réalisés directement dans le fichier HTML.

## Fonctionnalités

- Mise en page responsive
- Design clair et épuré
- Informations de présentation

## Technologies utilisées

- HTML5
- CSS3 (intégré directement dans le HTML)
